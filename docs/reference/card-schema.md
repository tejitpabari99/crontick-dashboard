# Card schema reference

A card is one UTF-8 JSON file `<feed>/<id>.json` holding an envelope plus a type-specific `data` object. The model is in [cards-and-feed](../concepts/cards-and-feed.md) and [card-types](../concepts/card-types.md); this page is the exact contract. Source of truth: the zod types in `src/contract/`; machine-readable form in `schemas/`.

## Machine-readable artifacts

- `schemas/card.json` full card (envelope + per-type data + kinds), `schemas/envelope.json`, and `schemas/<type>.json` for `markdown`, `table`, `list`, `kpi`, `media`. Generated by `npm run gen:schemas`; print one with `crontick-dashboard templates <type> --schema`.
- `templates/<type>.example.json`: a valid example per type; print with `crontick-dashboard templates <type>`.
- JSON Schema cannot express everything. Validator-only rules: id pattern details, RFC 3339 checks, cron validity, filename match, duplicate list item ids, link/src rules. Use `validate` as the authority.
- Templates carry their own ids, so `validate templates/x.example.json` fails with `id-mismatch`; pipe instead: `crontick-dashboard templates list | crontick-dashboard validate -`.

## File rules

| Rule | Detail |
|------|--------|
| Encoding | Valid UTF-8 text; a leading BOM is tolerated |
| Size | At most 1 MiB (`too-large` otherwise) |
| Top level | A JSON object (not array, scalar, or empty file) |
| Filename | `<id>.json`; the stem must equal `id` (`id-mismatch`). Case-insensitive `.json`. |
| Unknown fields | Preserved everywhere, never stripped. Keys starting `x-` are reserved for agents; the contract will never use them. |

## Envelope

| Field | Type | Required | Default | Rules |
|-------|------|----------|---------|-------|
| `id` | string | yes | | Matches `^[a-z0-9][a-z0-9._-]{0,63}$`, not ending in `.`, base name before the first `.` not a Windows reserved name (`con prn aux nul com1-9 lpt1-9`) |
| `kind` | `"panel"` or `"alert"` | yes | | Panels live in the grid, alerts in the top strip until ticked |
| `type` | string | yes | | One of `markdown table list kpi media`; others are `unknown-type` |
| `title` | string | yes | | 1-200 chars |
| `updatedAt` | string | yes | | RFC 3339 timestamp with offset or `Z` (naive local time rejected). Bump on every rewrite; a change resets Done and re-notifies |
| `priority` | integer | no | `2` | 0-5 |
| `notify` | boolean | no | `false` | OS notification on new `updatedAt` |
| `show` | object | no | always visible | `{ cron, for? }` |
| `show.cron` | string | yes in `show` | | Standard 5-field cron (no aliases, no seconds): the window start |
| `show.for` | duration | no | until end of that local day | Window length |
| `staleAfter` | duration | no | never | Card shows Broken (`stale`) once older than this |
| `retention` | duration | no | config `retentionDefault` | How long archived versions are kept |
| `size` | `"S"`, `"M"`, `"L"` | no | `"M"` | Grid size hint |
| `error` | string or null | no | `null` | Non-empty string declares an error card: shown Broken with this message, `data` not validated. Empty string is treated as null |
| `data` | object | yes unless `error` is non-empty | | Per-type body below |

Durations: `^[1-9]\d*(m|h|d|w)$`, at most 3650d (e.g. `30m`, `12h`, `7d`, `2w`). Allowed kinds per type: `markdown`, `list`, `kpi` accept `panel` or `alert`; `table` and `media` accept `panel` only (else `schema-invalid`, `/type`).

Shared value formats:

- `link`: `http`, `https`, `mailto` or `ms-outlook` URL, at most 2048 chars, no whitespace or control chars.
- `due`: `YYYY-MM-DD` or RFC 3339 datetime with offset or `Z`.

## `markdown`

| Field | Type | Rules |
|-------|------|-------|
| `text` | string | required, at most 100000 chars; GitHub-flavored markdown |

## `table`

| Field | Type | Rules |
|-------|------|-------|
| `columns` | array | required, 1-50 entries; each a string label or `{ label, key?, sort? }` with `sort` in `text`, `number`, `date` |
| `rows` | array | required; each `{ cells, link? }`; `cells.length` must equal `columns.length` |
| cell | scalar or object | string, number, boolean, null, or `{ text, link? }` |
| `defaultSort` | object | optional `{ column, dir }`; `column` a valid column index, `dir` `asc` or `desc` |
| `searchable` | boolean | default `true` |

## `list`

| Field | Type | Rules |
|-------|------|-------|
| `items` | array | required (may be empty) |
| `emptyText` | string | optional text for an empty list |
| item `text` | string | required |
| item `id` | string | optional, non-empty; unique within the card; required when `action` is set |
| item `subtitle` | string | optional |
| item `checked`, `checkedAt` | boolean, RFC 3339 | optional; `complete` write-back sets them |
| item `due` | date or datetime | optional (shown in the browser's time zone, see [troubleshooting](../troubleshooting.md)) |
| item `link` | link | optional |
| item `links` | array of `{ text, link }` | optional, at most 5 |
| item `action` | `"dismiss"`, `"complete"`, or `{ type }` | optional. `dismiss`: one-way tick kept in server state. `complete`: the server edits `checked`/`checkedAt` in the card file |

## `kpi`

Canonical form `data.items`: 1-12 metrics. A single-metric flat form (metric keys directly in `data`) is accepted and normalized to `items`; using both is invalid.

| Metric field | Type | Rules |
|--------------|------|-------|
| `value` | string or number | required |
| `label`, `unit` | string | optional |
| `state` | `ok`, `pending`, `fail`, `warn` | optional |
| `trend` | `{ delta: number, dir?: up/down/flat, good?: up/down }` | optional |
| `link` | link | optional |

## `media`

| Field | Type | Rules |
|-------|------|-------|
| `items` | array | required, 1-50 |
| item `src` | string | required: `http(s)` URL or `data:image/*` URI |
| item `alt`, `caption` | string | optional |
| item `link` | link | optional |
| `layout` | `grid` or `single` | optional |

## Validation outcome

`validate` and the server run the same function. Failure reasons (Broken): see [errors.md](errors.md#broken-reasons). A passing card may carry warnings, currently only: `updatedAt` more than 5 minutes in the future (clock skew).
